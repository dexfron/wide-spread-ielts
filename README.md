# Wide-Spread IELTS

A vocabulary trainer for IELTS preparation.

**Status:** 🚧 In development (early stage)

## Goal

Help learners (starting with my sisters) memorize IELTS vocabulary and idioms through interactive cards and tests.

## Planned features

- [ ] Word list with translations (EN ↔ RU ↔ QAR)
- [ ] Flashcards (flip to see translation)
- [ ] Categories: idioms, phrasal verbs, topic vocabulary
- [ ] Quiz mode
- [ ] Progress tracking

## Tech stack

- **Backend:** Python (FastAPI) — planned
- **Frontend:** JavaScript — planned
- **Database:** SQLite — planned
